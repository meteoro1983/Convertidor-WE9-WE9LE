# Convertidor de option files WE9 ⇄ WE9LE (PC)

Convierte un option file de **Winning Eleven 9** a **WE9 Liveware Evolution** y al revés: reemplaza la
cabecera y los ajustes del sistema (primeros 9500 bytes) y verifica los checksums de los 10 bloques.
Jugadores, equipos, plantillas y kits no se tocan. Nunca modifica el archivo de entrada.

- Uso: arrastrá el option file sobre `arrastrar_aqui.bat` o sobre el `.exe` de **Releases**. Detalle en `LEEME.txt`.
- Compilar: `compilar_exe.bat` (PyInstaller).
